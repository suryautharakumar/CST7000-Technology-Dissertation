About This Tool

This project is an Automated Predictive Analysis AI Software Tool for Structured Data. It is designed to help users upload tabular datasets and automatically create predictive machine learning models.

Technologies Used

  • Frontend: HTML, CSS, JavaScript, Bootstrap
  • Backend: Python and Flask
  • Data Processing: pandas and NumPy
  • Machine Learning: scikit-learn
  • Charts: Chart.js

System Modules

  • Dataset upload and preview
  • Automatic preprocessing
  • Classification/regression detection
  • Machine learning model comparison
  • Feature importance and prediction output
